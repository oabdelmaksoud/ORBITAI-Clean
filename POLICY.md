# OrbitAI Repository Policy

This document defines access, contribution, and usage policies for this repository.

---

## Repository Access

This repository is **PRIVATE** and contains proprietary software. Access is restricted to authorized contributors only.

- Access is granted on a need-to-know basis by repository administrators.
- Sharing access credentials, tokens, or SSH keys with unauthorised parties is strictly prohibited.
- All contributors must have a signed contributor agreement on file before their first commit is accepted.
- Access is revoked immediately upon the end of employment, contract, or project participation.

---

## Contribution Policy

1. **Branching** — All work must be done on feature branches named `feat/`, `fix/`, `chore/`, or `docs/`. Direct pushes to `main` are not permitted.
2. **Pull Requests** — Every change requires a pull request reviewed and approved by at least one other authorised contributor before merging.
3. **Secrets** — No credentials, API keys, tokens, passwords, or private keys may be committed. Use `.env.example` to document required variables and store actual values in a secrets manager.
4. **Dependencies** — New third-party dependencies must be reviewed for license compatibility and known vulnerabilities before being added.
5. **Code Review** — Reviewers are responsible for checking correctness, security, and adherence to this policy.

---

## Data Handling

- OrbitAI may process user project data, code, and AI-generated artefacts. Contributors must handle this data with confidentiality.
- Personal data collected by the platform must be processed in accordance with applicable privacy regulations (GDPR, CCPA, etc.).
- Test data must be anonymised; real production data must never be used in development or staging environments without explicit authorisation.
- Data retained beyond its useful life must be securely deleted in accordance with the data-retention schedule.

---

## AI Output and Intellectual Property

- Code, documentation, or other artefacts generated by OrbitAI's AI features are produced on behalf of the end user or organisation operating the platform.
- The OrbitAI platform code itself is proprietary and owned by the project owner(s). No AI-generated output modifies this ownership.
- Contributors must not use OrbitAI's AI features to generate content that infringes third-party intellectual property rights.

---

## Acceptable Use

- This codebase and the platform it produces may only be used for lawful purposes.
- Use of OrbitAI-generated artefacts for malicious software, fraud, or any activity that violates applicable law is strictly prohibited.
- Reverse engineering, sublicensing, or reselling the platform without explicit written permission is not permitted.

---

## Security Incident Reporting

If you discover a security vulnerability in this repository or the running platform, do **not** disclose it publicly. Report it directly to the repository administrators by opening a private security advisory on GitHub or contacting the project owner directly.

---

## Policy Updates

This policy may be updated at any time. Contributors will be notified of material changes via the repository's communication channel. Continued contribution after notification constitutes acceptance of the updated policy.
