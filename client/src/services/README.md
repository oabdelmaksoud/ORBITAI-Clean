# Services

Frontend API services for communicating with the backend.

## Core Services

### Authentication & User
- `adminApi.ts` - Admin API endpoints
- `userSettingsApi.ts` - User settings
- `apiKeysApi.ts` - API key management

### LLM & AI
- `geminiService.ts` - Gemini AI integration
- `adminLLMRouterApi.ts` - LLM router settings
- `llmAnalyticsApi.ts` - LLM usage analytics
- `llmUsageApi.ts` - Usage tracking

### Features
- `featureFlagsApi.ts` - Feature flag management
- `brainstormingAgentApi.ts` - Brainstorming agent
- `supportApi.ts` - Support system
- `speechApi.ts` - Speech/audio handling

### Project Management
- `projectService.ts` - Project operations
- `projectStorage.ts` - Project persistence
- `prototypeGenerationService.ts` - Prototype generation

### Data & Content
- `pageBuilderApi.ts` - Page builder
- `templatesApi.ts` - Templates
- `knowledgeBaseApi.ts` - Knowledge base (if present)
