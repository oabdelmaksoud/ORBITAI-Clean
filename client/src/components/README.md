# Components

This directory contains all React components for the OrbitAI frontend.

## Structure

### Core Components
- `App.tsx` - Main application component (in root)
- `LandingPage.tsx` - Landing page
- `NeuralStreamChat.tsx` - Main chat/brainstorming interface

### Feature Modules
- `neural-stream-chat/` - Neural stream chat components
- `admin-dashboard/` - Admin dashboard tabs
- `page-editor/` - Page builder components
- `workflow/` - Workflow designer components
- `charts/` - Chart components
- `landing/` - Landing page sections

### Admin Components
- `AdminDashboard.tsx` - Main admin interface
- `AdminLogin.tsx` - Admin authentication
- `ApiKeyManager.tsx` - API key management
- `LLMModelManagement.tsx` - LLM model config
- `LLMRouterSettings.tsx` - Router configuration
- `AIRuleConfigurator.tsx` - AI routing rules

### UI Components
- `Toast.tsx` - Toast notifications
- `Tooltip.tsx` - Tooltips
- `ErrorBoundary.tsx` - Error handling
- `ConfirmationModal.tsx` - Confirmation dialogs

### Data Visualization
- `MindMapGraph.tsx` - Mind map visualization
- `OrbGraph.tsx` - Orb network graph
- `MermaidDiagram.tsx` - Mermaid diagrams
- `NetworkVisualizer.tsx` - Network visualization
